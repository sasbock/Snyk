# Snyk
A collection of scripts, tools, and utilities for working with the Snyk Platform. This repository provides automation and developer-focused tooling to streamline Snyk configuration, integration, reporting, and platform workflows.

## Scripts
- [`snyk-generate-cra-sbom-vex.py`](snyk-generate-cra-sbom-vex-README.md) — generates an aggregate, EU CRA-aligned SBOM and companion VEX document from Snyk Open Source/Container project data. **Intended for production use** — see its own README for details and disclaimer.
